# FDA Calendar Dashboard

A static site that displays upcoming FDA PDUFA decisions and AI-generated trading-signal
predictions, read live from Supabase.

**Live site:** https://srikaryallala.github.io/fda-calendar-dashboard/

## Architecture

```
MarketBeat FDA calendar --(weekly scraper, scheduled)--> Supabase.fda_calendar
Supabase.fda_calendar --(weekly 3-agent pipeline, scheduled)--> Supabase.agent_predictions
Supabase.fda_dashboard (view, joins the two) --(read-only, anon key)--> this site
```

- `fda_calendar` — upcoming PDUFA decisions (company, ticker, drug, indication, date),
  refreshed weekly.
- `agent_predictions` — output of a 3-agent pipeline run against tickers inside a 45-day
  window of their decision:
  1. **Biotech Analyst** — predicts Approval / CRL / Delay with a rationale grounded in
     trial data, regulatory designations, and precedent.
  2. **Probability Agent** — an independent, calibrated probability distribution across
     those three outcomes, anchored to historical FDA base rates.
  3. **Portfolio Manager** — synthesizes both agents plus live price/market cap into a
     bull/bear stock-move range, a probability-weighted expected move, and a directional
     stance.
- `fda_dashboard` — a Postgres view joining the two tables on the latest prediction run
  per ticker/drug/decision, which is what this site actually queries.

This site is a single static `index.html` — no build step, no framework. It queries
Supabase directly from the browser using the public (read-only) anon key; Row Level
Security on the underlying tables only grants `SELECT` to that key, so the site can never
write to the database.

## Local development

Just open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

## Deployment

Published via GitHub Pages from the `main` branch (see repo Settings &rarr; Pages).
No build step is required since the page fetches live data from Supabase on every load —
pushing to `main` only needs to happen when the page's code changes, not when the
underlying data refreshes.

## Disclaimer

Predictions are generated by AI agents from public web research. They are not investment
advice and are not a substitute for independent due diligence. PDUFA dates are sourced
from public trackers and can shift without notice.
